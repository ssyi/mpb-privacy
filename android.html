mPB for Android 개인정보처리방침

최종 업데이트: 2026년 8월 17일

수집하는 개인정보

mPB는 마라톤 대회 기록(날짜, 대회명, 코스, 완주 시간, 기록증 이미지·PDF, 인증 사진)을 사용자가 직접 입력하는 개인용 기록 관리 앱입니다. 앱은 자체 서버를 운영하지 않으며, 개발자 또는 제3자에게 어떠한 데이터도 전송·수집하지 않습니다. 계정 가입이나 로그인도 필요하지 않습니다.

데이터 저장 위치

  • 모든 기록과 첨부 파일(기록증·인증 사진)은 사용자의 Android 기기 내부 저장 공간에만 저장됩니다.
  • 앱은 클라우드 동기화를 제공하지 않습니다. 다른 기기로 기록을 옮기려면 앱의 백업(JSON) 내보내기 기능으로 파일을 만들어 사용자가 직접 옮겨야 합니다.
  • 사용자가 백업·CSV·PDF 파일을 저장하거나 공유하기로 선택한 경우, 그 파일의 이후 보관 위치(기기 저장소, 사용자가 선택한 클라우드 드라이브, 공유 대상 앱 등)는 사용자의 선택에 따르며 개발자는 관여하지 않습니다.

제3자 공유

mPB는 광고, 분석(analytics), 트래킹 SDK를 포함하지 않습니다. 어떠한 개인정보도 제3자와 공유하거나 판매하지 않습니다.

사진·파일 접근

기록증·인증 사진을 첨부할 때는 Android 사진 선택 도구(Photo Picker)와 파일 선택 도구를 사용하며, 사용자가 그 자리에서 직접 고른 항목만 앱에 복사됩니다. 앱은 사진 라이브러리 전체에 대한 접근 권한을 요구하지 않습니다.

데이터 삭제

앱 내에서 개별 기록을 삭제하면 해당 기록과 첨부 파일이 함께 삭제됩니다. 앱을 삭제하면 앱이 저장한 모든 데이터가 기기에서 삭제됩니다. 사용자가 별도로 내보낸 백업·CSV·PDF 파일은 사용자가 직접 삭제해야 합니다.

아동의 개인정보

mPB는 만 13세 미만 아동을 대상으로 하지 않으며, 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

mPB for Android Privacy Policy

Last updated: August 17, 2026

Information We Collect

mPB is a personal marathon race record-keeping app in which the user manually enters race data (date, race name, course, finish time, certificate images/PDFs, and photos). The app does not operate any server and does not transmit or collect any data to the developer or any third party. No account or sign-in is required.

Where Data Is Stored

  • All records and attachments (certificates and photos) are stored solely in the app's private storage on the user's Android device.
  • The app provides no cloud sync. To move records to another device, the user exports a backup (JSON) file with the app's export feature and transfers it themselves.
  • If the user chooses to save or share a backup, CSV, or PDF file, where that file subsequently resides (device storage, a cloud drive of the user's choosing, a receiving app) is the user's own choice and is outside the developer's control.

Third-Party Sharing

mPB contains no advertising, analytics, or tracking SDKs. No personal information is shared with or sold to any third party.

Photo and File Access

Attachments are chosen through the Android Photo Picker and the system file picker; only the items the user explicitly selects are copied into the app. The app does not request access to the full photo library.

Data Deletion

Deleting a record within the app also deletes its attachments. Uninstalling the app removes all data the app stored on the device. Backup, CSV, or PDF files the user exported must be deleted by the user.

Children's Privacy

mPB is not directed at children under 13, and we do not knowingly collect personal information from children.
